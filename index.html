Day 1: Python Runner

Antigravityで作る、初めてのPython Webアプリ

🎉 プロジェクト概要

このアプリケーションは、Webブラウザ上で簡単なPythonコードを実行できるツールです。Streamlitを使用して構築されており、標準出力やエラーメッセージをリアルタイムで確認できます。

GitHubリポジトリを見る アプリのデモを見る

🚀 機能

  • Pythonコードの記述と実行
  • 実行結果（標準出力・標準エラー）の表示
  • シンプルなWebインターフェース

💻 使い方

  1. リポジトリをクローンまたはダウンロードします。
  2. 必要なライブラリをインストールします: pip install -r requirements.txt
  3. アプリを起動します: streamlit run app.py
